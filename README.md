# RoastCalc

A cross-platform calculator application built with Flutter. 

RoastCalc functions as a standard calculator while featuring a distinct retro aesthetic. It integrates an AI "chill coworker" persona that periodically generates lighthearted text roasts based on the user's mathematical input history. It also includes a dedicated insights screen providing math tricks and shortcut strategies relevant to recent calculations.

## Architecture
This project enforces a strict layer-first architecture separating the core platform configuration, visual presentation, business domain, and data storage.
